# Ghenale Cakes • Giovanna Pastelería

> *«El dulce sabor de tus momentos»*
> Experiencia web artesanal inspirada en el diseño Haute Pâtisserie Atelier de Stitch para Ghenale Cakes en Sullana, Piura.

---

## 🌟 Características Principales

- **Arquitectura Modular en React + TypeScript + Tailwind CSS:** Código estructurado en componentes reutilizables, hooks y contextos.
- **Totalmente Responsive (Mobile-First):** Diseñado con barra de navegación inferior fija estilo app móvil y adaptación fluida a pantallas de escritorio (Desktop / Tablet).
- **Catálogo de Tortas Artesanales:** Búsqueda en tiempo real por nombre e ingredientes, filtrado por categorías (*Tortas Temáticas*, *Matrimonios & 15 Años*, *Clásicas Caseras*, *Postres & Keke*) y selector de porciones (*15-20*, *25-40*, *50+ pax*).
- **Cotizador de Tortas a Medida en 6 Pasos:**
  1. Selección de ocasión (Cumpleaños infantil, boda, bautizo, 15 años, etc.).
  2. Tamaño y estructura (de 15 a 100+ personas con cálculo de precio estimado en Soles).
  3. Tipo de masa (Keke tradicional, chocochips, novia, red velvet, naranja piurana).
  4. Relleno casero (Manjar blanco de olla, fudge a la leña, crema pastelera, mermelada norteña).
  5. Acabado (Masa elástica 3D, Chantilly, Buttercream, Naked cake con flores).
  6. Personalización de dedicatoria, fecha del evento y despacho (Recojo en taller o delivery en Sullana).
  - *Generación automática de mensaje estructurado para WhatsApp con 1 solo clic.*
- **Bocaditos & Packs para Fiestas:** Packs de 50, 100 y 200 bocaditos, y opciones a la carta por ciento / medio ciento con controles de cantidad.
- **Bolsa de Compras & Despacho Climatizado:**
  - Persistencia del carrito en `localStorage`.
  - Selector de transporte refrigerado (4°C) o retiro en taller en Sánchez Cerro.
  - Franja horaria y fecha de entrega.
  - Tarjeta caligráfica de cortesía para dedicatoria.
  - Cierre y confirmación directa por WhatsApp.
- **Información del Taller en Sullana & Canales de Contacto:**
  - Dirección física: *TRV. Santa Cecilia AA.HH Luis Miguel Sánchez Cerro Mz. A7 Lt. 04, Sullana, Piura*.
  - Referencia: Cerca a la Cancha Techada Sánchez Cerro.
  - Enlace directo a Google Maps / Waze.
  - Llamadas y WhatsApp directo al **997 404 726**.
  - Métodos de pago locales integrados (Yape, Plin, BCP, BBVA y efectivo).

## 🚀 Instalación y Ejecución Local

1. Clonar el repositorio:
```bash
git clone https://github.com/DavidDevXPe/ghenale.git
cd ghenale
```

2. Instalar dependencias:
```bash
npm install
```

3. Iniciar el servidor de desarrollo:
```bash
npm run dev
```

4. Compilar para producción:
```bash
npm run build
```
